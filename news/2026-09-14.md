> 📖 **用語解説：第3号被保険者って？**

**何が起きた？**
厚生労働省が、専業主婦などを対象とした国民年金の「第3号被保険者制度」の縮小に向けた本格的な検討に入ったというニュースだよ。共働き世帯が増加する社会構造の変化や、制度間の不公平感を是正する狙いがあるんだ。今後の法改正に向けた議論の行方は、パートで働く主婦層の働き方や社会保険の加入選択に大きな影響を与えるため、各方面で波紋を呼んでいるよ。

**うちの仕事にどう関係する？**
- [ ] 顧問先のパート従業員から「働き損」や扶養の壁に関する相談への対応準備をしておく
- [ ] 社会保険の適用拡大の動きとあわせ、クライアント企業の給与・労務設計への影響をシミュレーションする
- [ ] 今後の制度変更を見据え、労働時間や賃金設定に関するアドバイスを整理しておく

| 🧑 労働者目線 | 「これまで認められていた優遇が縮小されることで、家計の負担が増えるのではないかと心配だ」 |

## ③ 令和8年10月から始まる「国民年金保険料の育児免除制度」を案内するチャットボットを開設——日本年金機構（全国）

> 📖 **用語解説：国民年金第1号被保険者って？**
> 日本国内に住む20歳以上60歳未満の人で、会社員（第2号被保険者）やその被扶養配偶者（第3号被保険者）以外の人のことだよ。自営業者やフリーランス、学生などがこれに該当するんだ。

**何が起きた？**
日本年金機構は、**2026年10月**から新たに始まる「国民年金保険料の育児免除制度」に関する疑問に答えるため、「ねんきんチャットボット」での案内サービスを**2026年9月11日**より開始したよ。自営業やフリーランスなどの第1号被保険者が、1歳未満の子を養育する場合に保険料が免除されるこの新制度について、対象者の条件や免除期間などを24時間いつでも手軽に確認できるようになっているんだ。

**うちの仕事にどう関係する？**
- [ ] フリーランスや個人事業主である顧問先やその従業員からの、育児免除に関する問い合わせに備える
- [ ] 新制度の要件や届出方法について、事務所内の相談マニュアルをアップデートする
- [ ] 日本年金機構のチャットボット等のツールを活用した効率的な情報収集をクライアントに案内する

## ⑤ 9月は「職場の健康診断実施強化月間」——厚労省が事後措置やストレスチェックの徹底を要請（全国）

> 📖 **用語解説：健康診断の「事後措置」って？**
> 医師の健康診断結果に基づき、異常の所見があると診断された労働者について、就業上の措置（就業制限や時間外労働の制限など）が必要かどうかを医師の意見を聴いて決定し、適切に講じること。

**どういう話？**
厚生労働省は9月を「職場の健康診断実施強化月間」と定め、定期健康診断の確実な実施と、その後の適切な事後措置、さらにストレスチェック制度の有効活用を全国の事業所に呼びかけている。労働安全衛生法に基づく健康診断は実施するだけでなく、異常所見者に対する医師からの意見聴取や、必要に応じた就業上の配慮を行わなければ法的な義務を果たしたことにならない。実務では「受けっぱなし」になりがちな健康診断のフォローアップ体制の総点検が急務となっている。

**うちの仕事にどう関係する？**
- [ ] 健康診断の受診率だけでなく、結果に基づく「医師の意見聴取」や「事後措置」が確実に行われているか確認する
- [ ] 10月に義務化・改正が控える実務と合わせ、社内の衛生委員会等で健康管理体制を見直す
- [ ] ストレスチェックの未実施者や高ストレス者への面接指導の勧奨がスムーズに機能しているか点検する

| 立場 | 意見・懸念点 |
| :--- | :--- |
| **経営者** | 従業員の健康管理は投資だが、小規模事業所では産業医との連携や事後措置の対応に手間とコストがかかるのが悩み。 |
| **労働者** | 再検査や医師の面談を勧められても、業務が忙しくてつい放置しがちなので、会社から強制ではなく丁寧なサポートがほしい。 |
| **現場管理者** | メンバーが健康上の理由で就業制限や時短勤務になると現場の負担が増えるため、配慮と人員確保のバランスが難しい。 |
| **専門家（社労士等）** | 健康診断の未実施や事後措置の不備は、万が一の過労死・病気休職の際に安全配慮義務違反を問われる致命傷になるため厳しく指導している。 |

## ⑥ 📚コラム：【社労士警告】今年の最低賃金アップは「昨年より小幅」と油断するな！月給制社員の時給換算に潜む落とし穴

> 📖 **用語解説：最低賃金の「時給換算」って？**
> 月給制や日給制の賃金を、それぞれの1ヶ月平均所定労働時間や1日あたりの所定労働時間で割り、時間給に直して都道府県別の最低賃金と比較すること [1.1.1]。

**どういう話？**
今年の地域別最低賃金の改定では、上げ幅が昨年と比較して小幅にとどまる地域や議論が割れる地域もあるが、「今年は大して上がらなかったから大丈夫」と油断するのは非常に危険だ。基本給だけでなく、各種手当（通勤手当や家族手当などを除外して計算する場合のルール）の除外規定の確認漏れや、年々引き上げられるベースに引きずられて、一部の月給制社員の「時間給換算」がうっかり最低賃金を下回ってしまうケースが多発している。特にパート・アルバイトだけでなく、低めの基本給に固定残業代を組み込んでいる正社員の契約は要注意である。

**うちの仕事にどう関係する？**
- [ ] 自社のすべての雇用形態（特に月給制の低額層）について、最新の最低賃金を用いた時給換算シミュレーションをやり直す
- [ ] 固定残業手当が最低賃金の計算から除外される賃金に該当するかどうか、給与項目の見直しを行う
- [ ] 改定後の最低賃金が発効するまでに賃金台帳の改定漏れがないかチェック体制を整える

| 立場 | 意見・懸念点 |
| :--- | :--- |
| **経営者** | 最低賃金が上がるとパートだけでなく全体の給与バランス（ベースアップ要求）に波及するため、人件費の予測が非常に苦しい。 |
| **労働者** | 物価高が続いているのに、最低賃金があまり上がらない地域では生活が苦しいまま取り残されてしまう実感がある。 |
| **現場管理者** | 時給が上がるのは良いが、それに伴ってシフトの調整や予算管理を厳しく求められるので現場のマネジメントが大変。 |
| **専門家（社労士）** | 「うちは月給だから関係あるまい」と勘違いしている経営者が多い。時給換算のミスは労働基準法違反の直結リスクなので徹底的に洗うべき。 |

> 📖 **用語解説：諭旨解雇（ゆしかいこ）って？**
> 懲戒解雇に相当する事由がある場合に、会社側が「自主的な退職届を出すように諭し、従わない場合に懲戒解雇とする」という処分。実質的な懲戒処分の一種 [1.2.7]。

**どんな話？**
病院の不正や不祥事を内部告発した医師に対し、病院側が報復として「諭旨解雇」という重い処分を下した信じがたい事件。自浄作用を働かせようとした正義の告発者に対し、経営陣が逆ギレして放り出したこの暴挙に、裁判所は一切容赦しなかった。熊本地裁は、病院側の解雇権の濫用をバッサリと斬り捨て、解雇が無効であると宣言。さらに、精神的苦痛に対する損害賠償などを含め、総額約2,500万円もの巨額の支払いを病院側に命じた。公益通報者を守るべき医療現場で起きた闇を、司法の力で完全粉砕した痛快な事例である [1.2.7]。

**うちの仕事にどう関係する？**
- [ ] 内部告発（公益通報）を行った労働者に対する不利益取扱いは、法律で厳に禁じられており、発覚した場合は組織の社会的信用が完全に失墜する
