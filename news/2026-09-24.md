## ① 100日後に最高の上司になる：エンゲージメント向上の秘訣（全国）

> 📖 **用語解説：エンゲージメントって？**
> 会社に対する愛着や「この仕事をもっと頑張りたい！」っていう自発的なやる気のことなんだ。単なる満足度とは違って、チームや上司との信頼関係がカギになるよ。

**何が起きた？**
ビジネスパーソン向けメディア「日本人事部」において、エンゲージメント向上の秘訣に迫る特別企画が展開されているよ。組織の雰囲気を劇的に変え、部下のやる気を引き出すためのマネジメント手法や、日々のコミュニケーションにおける具体的なアプローチについて詳しく解説が行われているんだ [GitHub Issue #3 #17]。

- [ ] 従業員満足度（ES）やエンゲージメント調査の実施を検討している企業へ、適切なツールや助成金の活用を案内する

## ② 専業主婦など国民年金「第3号」厚労省が縮小に向け検討開始（全国）

> 📖 **用語解説：国民年金「第3号被保険者」って？**
> 会社員や公務員に扶養されている配偶者（主に専業主婦・夫）のことで、自分で保険料を払わなくても将来の年金がもらえる特別な仕組みなんだよ。

**何が起きた？**
厚生労働省が、専業主婦などを対象とする国民年金の「第3号被保険者」制度について、適用範囲の縮小に向けた本格的な検討に入ったことが明らかになったよ。少子高齢化や働き方の多様化が進む中、社会保険制度の公平性を高めるための大きな見直しとして、今後の動向に大きな注目が集まっているんだ [GitHub Issue #4]。

**うちの仕事にどう関係する？**
- [ ] パートタイム労働者等から「扶養の範囲内で働くべきか、外れて働くべきか」という相談を受けた際、今後の制度変更の可能性を踏まえたアドバイスを準備する
- [ ] 企業の社会保険適用拡大に伴う、配偶者手当や扶養手当の見直しに関する人事コンサルティングの準備を進める

**立場によって意見が分かれそうなポイント**

| 立場 | 出てきそうな意見 |
|---|---|
| 👔 経営者目線 | 「短時間勤務のスタッフが『年金の壁』を気にせず、もっと長く働いてくれる環境になれば人手不足の解消につながる」 |
| 🧑 労働者目線 | 「今まで免除されていた保険料を自分で払うことになると、家計の負担が一気に増えてしまうから不安…」 |
| 🏢 現場管理者目線 | 「社会保険の適用が変わることで、シフト調整や扶養内希望者の働き方に直接影響が出るので現場も対応が必要だ」 |
| ⚖️ 専門家目線 | 「制度の持続可能性を考えればやむを得ないが、急激な負担増で労働供給が冷え込まないような激変緩和措置が不可欠」 |

> 📖 **用語解説：足下の賃上げ**
> （あしたのちんあげ）補助金の申請から完了までの事業期間を待たず、応募時点で直近決算期からすでに従業員の給与を引き上げているか、または計画的に行っているかを評価する仕組みのこと。

**どういう話？**
中小企業庁が推進する「中小企業省力化投資補助金（一般型）」の第8回公募申請の受付が始まった。人手不足に悩む中小企業がIoTやロボットなどのデジタル技術を導入し、省力化と生産性向上を図るための費用を補助する制度だ。今回の第8回公募では、労働生産性や1人当たり給与支給総額を算定する「基準年度」の定義が、これまでの「応募申請時の直近決算期」から「補助事業が完了した日を含む事業年度の決算期」へと後ろ倒し変更された。これにより、申請から完了までの間の賃上げ実績も厳しく見られるほか、審査項目に「足下の賃上げ」が明示されるなど、実質的なハードルが上がっている。

**うちの仕事にどう関係する？**
- [ ] 補助金を申請する顧問先に対し、第8回からの「基準年度」の変更や「足下の賃上げ」要件を周知する
- [ ] 3〜5年の事業計画で、労働生産性の年平均4.0%以上・給与支給総額の年平均3.5%以上の達成見込みを確認する

## ⑦ 🥊今日のスカッと労働判例：身勝手な理由で同僚を告発し病院を混乱させた医師の「諭旨解雇」——熊本地裁が下した、処分の均衡性と公益通報の重み

> 📖 **用語解説：処分の均衡性**
> 労働者が犯した違反行為やトラブルの重さと、会社側が下した懲戒処分（解雇、減給、戒告など）の重さが、社会通念上バランスが取れているべきという原則。

**どんな話？**
くまもと県北病院で起きた、前代未聞のドロ沼トラブル。同僚医師が自分の名義を無断使用して電子カルテを操作し、向精神薬の処方箋を偽造していた不正を発見した和田医師。病院側に報告したものの「口頭注意」で済まされたため、県警や自治体の首長に外部告発を行った。これに激怒した病院側は、なんと不正を行った同僚医師には「戒告」という軽い処分で済ませた一方、告発した和田医師に対しては「処方箋偽造の漏えい」などを理由に一発で「諭旨解雇」という重いペナルティを叩きつけたのだ。「不正を暴いた者がクビで、隠蔽に等しい同僚が軽い処分とは何事か！」と立ち上がった和田医師が解雇無効を求めて提訴。熊本地裁は、不正を行った者と告発した者との処分のバランスが全く取れておらず、公益通報者としての保護にも値するとして、諭旨解雇を完全に無効と判断。未払い賃金等約2,500万円の支払いを命じる、会社側にとっては痛快なまでの大逆転・粉砕判決となった！

**うちの仕事にどう関係する？**
- [ ] 内部告発やコンカライアンス違反の通報があった際、通報者を不利益に取り扱う「報復人事」や過剰な懲戒処分は裁判所で絶対に通用しないと肝に銘じる
- [ ] 処分を検討する際は、違反行為の重大性だけでなく「他の関係者との処分のバランス（均衡性）」が厳しく審査されることを意識する
- [ ] 就業規則の懲戒規定や公益通報者保護の社内窓口・フローを今一度総点検する

**立場によって意見が分かれそうなポイント**

| 立場 | 意見・懸念点 |
| :--- | :--- |
| **経営者** | 内部の機密や不祥事をいきなり外部の警察や自治体に駆け込まれた経営陣としては、組織の秩序を乱した懲戒もやむを得ないと感じる |
| **労働者** | 内部通報してもみ消されるような職場で、正義を貫いた人が不当にクビにされない司法の判断は非常に心強い |
| **現場管理者** | 院内や社内の人間関係がギスギスし、トラブルが起きたときにどう収拾つければいいか頭を悩ます |
| **専門家（社労士・弁護士）** | 会社の面子や感情で処分を決めると、裁判で一発レッドカードを食らう典型例。冷静なリスクアセスメントが不可欠 |
