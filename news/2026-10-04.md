## ① 100日後に最高の上司に-エンゲージメント向上の秘訣（全国・全業種）

**何が起きた？**
組織の生産性や離職防止の切り札として注目される「従業員エンゲージメント」を高めるための実践的なアプローチやノウハウが、人事・労務メディア等で連日特集されているんだ。単なる一過性のイベントや福利厚生の拡充ではなく、企業理念の浸透から公平な評価制度の構築、上司と部下の日常的なコミュニケーションの質向上まで、組織全体で取り組むべき具体的なステップが解説されているよ。慢性的な人手不足が続く中、従業員が「この会社で働き続けたい」と思える環境づくりの重要性が一段と高まっているという話だね。

**うちの仕事にどう関係する？**
- [ ] クライアント企業の人事評価制度や賃金体系が、従業員のエンゲージメント向上につながっているかヒアリング・見直し提案を行う
- [ ] 単なる労働条件の整備にとどまらず、社内コミュニケーション活性化のための助成金活用や研修企画をサポートする
- [ ] 従業員満足度調査（サーベイ）の結果を活用した労務環境改善のアドバイスを提供する

**立場によって意見が分かれそうなポイント**

| 立場 | 出てきそうな意見 |
|---|---|
| 👔 経営者目線 | 「エンゲージメント向上は長期的な企業価値や生産性アップに直結するため、積極的に投資していきたい」 |
| 🧑 労働者目線 | 「形だけのスローガンやサーベイ実施ではなく、適正な評価やリアルな処遇改善を実感させてほしい」 |
| 🏢 現場管理者目線 | 「日々の業務に追われる中で、メンバーのエンゲージメントまでケアする余裕や時間を確保するのが難しい」 |
| ⚖️ 専門家目線 | 「人事制度の改定と現場のマネジメント改革を連動させなければ、一時的な施策で終わってしまうリスクがある」 |

## ② 専業主婦など国民年金「第3号」縮小に向け検討開始（全国・全世代）

**何が起きた？**
厚生労働省の有識者検討会において、会社員や公務員に扶養される配偶者を対象とした国民年金の「第3号被保険者制度」について、将来的な対象縮小に向けた本格的な議論がスタートしたよ。1995年度末に約1,220万人だった加入者は、共働き世帯の増加や女性の社会進出により、2025年度末には約604万人へと半減している。制度の維持には共働き世帯や単身者全体の保険料負担が伴うため、「サラリーマン世帯の専業主婦に対する優遇ではないか」との不公平感が根強く指摘されてきたんだ。厚労省は2万人規模の大規模実態調査を行い、2030年の年金制度改正に向けた具体的な見直し内容を詰めていく方針だ。

**うちの仕事にどう関係する？**
- [ ] クライアント企業の従業員やその配偶者に対し、今後の年金制度見直しや社会保険適用拡大の動向に関する情報提供を行う
- [ ] パートタイム労働者が「年金の壁」を過度に意識せず働けるよう、社内の給与・労働時間設計の相談に乗る
- [ ] 事務所の顧問先企業向けに、年金・社会保険改正のスケジュールをまとめたニュースレター等を発行する

**立場によって意見が分かれそうなポイント**

| 立場 | 出てきそうな意見 |
|---|---|
| 👔 経営者目線 | 「短時間労働者の社会保険適用拡大とあわせ、従業員が就業調整せずに長く働ける環境へシフトしてほしい」 |
| 🧑 労働者目線 | 「介護や育児などの事情で外で十分に働けない主婦層もいるため、一律の縮小や廃止には不安がある」 |
| 🏢 現場管理者目線 | 「扶養の枠を気にして秋口以降にシフトを急に減らすパートスタッフが減ってくれれば、現場のシフト管理がラクになる」 |
| ⚖️ 専門家目線 | 「制度の不公平感の是正は不可避だが、すべての国民を公的年金でどう支えるか、慎重な移行期間の設定が必要だ」 |

## ⑤📚コラム：【10月施行開始】「残業月45時間の一律指導廃止」は本当に規制緩和なのか？労基署の“本気”の狙いを読み解く

> 📖 **用語解説：労働基準監督署の監督指導**
> 労働基準法などの法律が守られているかを調査・指導するため、事業所へ臨検（立ち入り調査）等を行い、改善を促す行政活動のこと。

**どういう話？**
2026年9月から、労働基準監督署による企業の時間外労働に対する監督指導の方針が大きく見直された。これまで多くの現場で実施されてきた、一律に「月45時間以内への削減」を機械的に求める指導スタイルが改められたのだ。これを聞いて「残業規制が緩くなったのか」と胸をなで下ろす経営者もいるかもしれないが、それは大きな勘違いである。狙いは規制緩和ではなく、形骸化した一律指導から、各社が締結している36協定の内容や、実際の「健康確保措置の実施状況」を深く見極める個別的かつ実質的な審査へのシフトである。

**うちの仕事にどう関係する？**
- [ ] 自社の36協定の届出内容と、実際の勤怠管理システム上の時間外労働が乖離していないか点検する
- [ ] 「月45時間以内だから安心」ではなく、長時間労働者の健康障害防止対策（医師の面接指導など）が確実に機能しているか確認する
- [ ] 労基署の調査が入った際に、単なる時間数だけでなく「健康管理のプロセス」を説明できる証拠を残す

| 立場 | 意見・懸念点 |
| :--- | :--- |
| **経営者** | 一律の縛りが緩んだなら少し残業が増えても対応しやすくなるのではと期待半分、個別指導の厳格化に警戒半分。 |
| **労働者** | 「45時間を超えてもいい」と会社が勘違いして、過労につながるような長時間労働が野放しにならないか不安。 |
| **現場管理者** | 単純な時間数管理だけでなく、部下の心身の健康状態や業務負荷のバランスまで見なければならず管理責任が重くなる。 |
| **専門家（社労士）** | 「規制緩和ではない」点を経営者に強く周知し、36協定の適法性と実態の健康管理体制のセットでの見直しを急ぐ必要がある。 |

## ⑥📚コラム：【実務の勘違い】「うちは全員正社員だから関係ない？」パート・有期雇用の同一労働同一賃金で陥りがちな3つの罠

> 📖 **用語解説：同一労働同一賃金**
> 同じ企業で働く正社員と非正規雇用労働者（パートタイム労働者、有期雇用労働者、派遣労働者）との間で、不合理な待遇差を設けることを禁止する法原則。

**どういう話？**
2026年10月の法改正施行に伴い、パートタイム・有期雇用労働法に関するルールやガイドラインが一段と厳格化された。現場でよくある最大の勘違いが、「うちの会社は正社員と名前のつく雇用形態しかいないから、非正規向けの同一労働同一賃金は関係ない」という思い込みだ。しかし、ここでいう「パート・有期」の定義は名称ではなく実態。また、賞与や各種手当（家族・住宅・皆勤等）だけでなく、教育訓練の機会の提供や福利厚生に至るまで、「なぜこの差があるのか」を論理的に説明できる根拠がなければ、すべて法的リスクに直結する。

**うちの仕事にどう関係する？**

- [ ] 各種手当や福利厚生、さらに「研修や教育訓練の受講機会」に不合理な格差がないか点検する
- [ ] 10月以降、雇入れ時の労働条件通知書に「待遇差の説明を求められる旨」が正しく記載されているか確認する

| **労働者** | 長年同じ仕事をしていながら、正社員との間に納得のいかない格差があったため、しっかり説明してもらえるのはありがたい。 |

## ⑦🥊今日のスカッと労働判例：同僚の不正告発をしたら「諭旨解雇」の罠…！裁判所が下した痛快な“許されざる報復無効”判決

> 📖 **用語解説：諭旨解雇（ゆしかいこ）**
> 懲戒解雇に準じる重い処分だが、会社が一定の猶予や自主退職を促す形式をとるもの。実質的には事実上のクビを意味する。

**どんな話？**
病院に勤務していたベテラン医師（62歳）が、同僚医師が自身の名義を勝手に使って電子カルテを操作し、向精神薬の処方箋を偽造していた不正を発見！直ちに病院側に報告したものの、返ってきたのは「口頭注意」というおざなりな対応だった。納得がいかない医師が外部の行政や警察に通報したところ、逆恨みした病院側はなんと、その告発した医師本人に対して「処方箋偽造・情報漏えい」という濡れ衣に近いこじつけの理由をかぶせ、まさかの「諭旨解雇」を叩きつけたのだ！
これに激怒した医師が処分の無効と未払い賃金を求めて提訴。熊本地裁は、実際に処方箋を偽造した同僚には「戒告」という軽い処分にとどめておきながら、不正を正そうとした告発者には即解雇という極刑を下したそのアンバランスさを一刀両断。「処分の均衡性を完全に欠いており、社会通念上相当とは言えない」として諭旨解雇を無効と断じ、未払い賃金等約2,500万円の支払いを容赦なく命じた！正義を貫いた側が勝訴した、胸のすくような判決である。

**うちの仕事にどう関係する？**
- [ ] 内部告発やコンカライアンス上の通報を行った労働者に対して、報復人事や不利益な懲戒処分を行うことは絶対にご法度であると再認識する
- [ ] 懲戒処分を検討する際は、違反行為の重大性と処分の重さが釣り合っているか（処分の均衡性）を厳格に検証する
- [ ] 組織内の不正隠蔽体質を放置せず、健全な内部通報制度とクリーンなガバナンスを構築する

| 立場 | 意見・懸念点 |
| :--- | :--- |
| **経営者** | 組織の不祥事を外部に漏らされたように感じると感情的に厳罰に処したくなるが、報復と受け取られる処分は裁判で完敗するリスクが極めて高い。 |
| **労働者** | 不正を見過ごさずに声を上げた人が不当に追い出されるような会社では安心して働けない。司法がしっかり守ってくれて心強い。 |
| **現場管理者** | 現場で起きたトラブルや不正を隠すのではなく、速やかに適正なルートで自浄作用を発働させなければ会社全体が致命傷を負う。 |
| **専門家（社労士）** | 懲戒処分の有効性判断において「処分の均衡性」がいかに重視されるかを事例として示し、経営者の感情的な処分を制止する防波堤となる。 |
