## 1. 技能実習の監督指導、違反率71.7%に（東北6労働局）

**① 専門用語解説**
- **技能実習実施機関**：外国人技能実習生を実際に受け入れて実習を行わせる企業・事業場のこと。
- **監督指導**：労働基準監督署が事業場に立ち入り、労働基準関係法令（労基法・安衛法・最賃法等）の遵守状況を確認する行政指導。

**② ニュースの本文要約**
東北6労働局が令和6年に実施した技能実習実施機関への監督指導結果を公表した。実施事業場数は836事業場と令和元年以降で最多となり、そのうち71.7%にあたる599事業場で労働基準関係法令違反が確認された。件数・違反率ともに高水準で、外国人材受入れの拡大に監督体制の実効性が追いついていない可能性を示す数字であり、技能実習から育成就労制度への移行が進む中でのタイミングという点も気になるポイント。

**③ 実務対応（ToDo）**
- [ ] 技能実習生・特定技能外国人を受け入れている顧問先の一覧を洗い出す
- [ ] 36協定・賃金台帳・時間外労働の実態を年内に点検（特に割増賃金と寮費控除の適正性）
- [ ] 育成就労制度への移行スケジュールを顧問先に案内し、監理団体・登録支援機関との役割分担を再確認
- [ ] 是正指導が入った場合の初動対応フロー（是正報告書作成支援等）を事務所内で整理

**④ 立場別の意見の分かれ方**
- **経営者**：人手不足の中での監督強化に「摘発偏重で、体制構築支援が薄い」との不満も。
- **労働者（技能実習生）**：保護強化を歓迎する一方、相談窓口の周知不足が課題との声。
- **現場管理者**：多国籍化する現場での労務管理の複雑さに、実務レベルでの指導・様式提供を求める声。
- **専門家（社労士等）**：違反率の高さは是正指導後のフォローアップ体制の弱さを示すという指摘があり、監督の"量"より"質"（再発防止支援）を重視すべきとの意見。

## 2. 派遣の同一労働同一賃金、労使協定「結び直し忘れ」が急増（愛知労働局）

**① 専門用語解説**
- **労使協定方式**：派遣労働者の同一労働同一賃金を実現する2つの方式のうちの一つ。派遣元が労働者過半数代表等と賃金水準等を定めた労使協定を締結し、それに基づき待遇を決定する方式（もう一つは派遣先均等・均衡方式）。
- **協定の結び直し**：労使協定は原則1年ごとに見直し・再締結が必要で、これを怠ると協定方式の要件を満たさなくなる。

**② ニュースの本文要約**
派遣元事業主が労使協定方式を採用する際に必要な協定の更新（結び直し）を失念するケースが相次いでおり、愛知労働局における是正指導件数は前年比6割増となった。協定が失効した状態で運用を続けると、派遣先均等・均衡方式が適用されたとみなされ得るなど、賃金決定の根拠自体が崩れるリスクがある点が実務上大きな懸念材料。

**③ 実務対応（ToDo）**
- [ ] 労使協定方式を採用している派遣元顧問先の協定有効期間を一覧化
- [ ] 更新期日の1〜2か月前に自動リマインドが飛ぶ仕組み（カレンダー管理）を事務所側で構築
- [ ] 協定の記載事項（賃金額の根拠となる統計、地域指数の反映等）が最新版になっているか確認
- [ ] 協定切れが発覚した場合の遡及是正・派遣先への説明方法を事前にシミュレーション

**④ 立場別の意見の分かれ方**
- **経営者（派遣元）**：更新実務が煩雑で、行政の様式・チェックリスト整備を求める声。
- **労働者（派遣社員）**：待遇決定の根拠が曖昧になることへの不安、賃金遡及是正への期待。
- **現場管理者（派遣先）**：協定切れによる均等・均衡方式への切替えが発生すると実務負担が増すとの懸念。
- **専門家**：制度自体が複雑で「うっかりミス」を誘発しやすい構造にあり、制度簡素化を求める意見もある。

**⑤ 情報源**
- [労働新聞社 2026年8月ニュース一覧](https://www.rodo.co.jp/news/date/2026/08/)

## 3. 令和8年8月1日から育児休業等給付の申請手続きを見直し（厚労省）

**① 専門用語解説**
- **出生時育児休業給付金**：産後パパ育休（出生時育児休業）取得中の所得補償として支給される給付金。
- **出生後休業支援給付金**：両親がともに一定期間育休を取得した場合等に上乗せで支給される給付金。
- **育児時短就業給付**：育児のための時短勤務により賃金が低下した場合に支給される給付金（2025年創設）。

**② ニュースの本文要約**
厚生労働省は、事業所等の事務負担軽減のため、令和8年8月1日から育児休業等給付に関する3つの事務取扱いを見直す。①出生時育児休業給付金の申請時に申告する賃金の取扱いを見直し、実際の支払額確定前でも早期申請が可能に、②出生後休業支援給付金の配偶者確認書類として「母子健康手帳の写し」の提出を認める、③同一の子について既に育休給付を受給済みの場合、育児時短就業給付申請時の母子健康手帳等の再提出を不要にする。いずれも書類の重複提出・申請の時間的空白を解消する実務簡素化であり、施行がまさに本日（8月1日は既に経過、8月中の運用開始）という点でタイムリーな実務論点。

**③ 実務対応（ToDo）**
- [ ] 顧問先の給与・人事担当者に3つの見直し内容を一枚もののリーフレットで周知
- [ ] 出生時育休給付の申請タイミングを前倒しできるケースがないか、現在進行中の案件を棚卸し
- [ ] ハローワーク提出書類チェックリストを最新の取扱いに更新
- [ ] 育児時短就業給付を利用中/予定の顧問先について、重複書類の削減を案内

**④ 立場別の意見の分かれ方**
- **経営者**：事務負担軽減は歓迎、給与計算ソフト・システム側の対応時期が気になる。
- **労働者**：給付の早期化・書類簡素化は歓迎する一方、制度の複雑さ自体は変わらないとの声も。
- **現場管理者（人事担当）**：運用変更に伴う社内マニュアル改訂の手間は増える。
- **専門家**：実務簡素化自体は評価するが、根本的な申請システムのデジタル化・自動化が本丸という指摘。

## 4. 令和8年度 雇用保険料率が引き下げ（一般の事業：14.5/1,000 → 13.5/1,000）

**① 専門用語解説**
- **雇用保険料率**：賃金総額に対する雇用保険料の割合。労使折半負担部分と事業主のみ負担する雇用保険二事業分から構成される。
- **雇用調整助成金**：景気変動等により休業を余儀なくされた事業主が、休業手当の一部の助成を受けられる制度。コロナ禍で支給が急増し、雇用保険財政悪化の一因となった。

**② ニュースの本文要約**
令和8年度の雇用保険料率が前年度から0.1%引き下げられ、一般の事業で14.5/1,000から13.5/1,000へ変更される。農林水産・清酒製造業は16.5→15.5/1,000、建設業は17.5→16.5/1,000。コロナ禍の雇用調整助成金支給急増による財政悪化を受け、令和4年10月以降引き上げが続いていたが、財政状況の改善に伴い令和7年度から段階的な引き下げに転じている。適用は令和8年4月1日以降最初に到来する締日の給与から。

**③ 実務対応（ToDo）**
- [ ] 給与計算システム・賃金台帳の料率設定が新料率に更新されているか確認（未確認の顧問先があれば至急対応）
- [ ] 4月以降の給与で旧料率のまま控除していないか、既払い分の点検・過徴収時の還付案内
- [ ] 労働保険年度更新（7月申告）時に新旧料率の期間按分が正しく計算されているか再確認
- [ ] 従業員向けに手取り増となる旨を分かりやすく説明する資料を用意（顧問先の労務広報支援）

**④ 立場別の意見の分かれ方**
- **経営者**：保険料負担軽減は歓迎、ただし恒久的な引き下げか一時的措置かは不透明との慎重な見方も。
- **労働者**：手取り増は歓迎するが、金額としては小幅であり実感が薄いとの声。
- **現場管理者（給与担当）**：料率改定の反映漏れによるミスを懸念、システム対応のタイミングに注意が必要。
- **専門家**：財政改善を評価しつつ、将来の景気後退時に再び急激な引き上げが起きるリスクへの備え（財政バッファの設計）を指摘する声もある。

## 5. 社会保険労務士会の会費が月300円引き上げへ

**① 専門用語解説**
- **社会保険労務士会**：都道府県ごとに設置される社労士の職能団体。登録者は入会が義務付けられ、会費を負担する。

**② ニュースの本文要約**
社会保険労務士会の会費が月額300円引き上げられることが決定した。実務への直接影響は小さいが、事務所運営コストとしては継続的な微増要因であり、値上げの背景（会務運営費の増加、研修事業の拡充等）を会員としてどう受け止めるかが論点になる。適用開始時期は資料によって記載が分かれており、原典での確認が必要。

**③ 実務対応（ToDo）**
- [ ] 自身の会費引き上げ時期・金額を所属の都道府県社労士会に確認
- [ ] 事務所の年間経費計画に反映
- [ ] 値上げの使途（研修・広報・相談体制強化等）を確認し、必要であれば会員として意見を提出

**④ 立場別の意見の分かれ方**
- **経営者（社労士事務所主宰）**：値上げ自体はやむを得ないとしつつ、使途の透明性を求める声。
