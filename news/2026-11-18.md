## ① 100日後に最高の上司に-エンゲージメント向上の秘訣（全国・全業種）

**何が起きた？**
組織の生産性や離職率に直結する「エンゲージメント（従業員の会社に対する愛着や仕事への熱意）」を高めるための実践的なアプローチに注目が集まっているよ。上司と部下のコミュニケーションの質を変え、日々のマネジメントを100日間でどのようにアップデートしていくか、その具体的なステップや成功の秘訣が解説されているんだ。単なる精神論ではなく、現場の行動変容を促すマネジメント手法として、多くの企業の人事部門から関心を集めているという話だよ [Github Issue由来]。

**うちの仕事にどう関係する？**
- [ ] 顧問先企業に対し、管理職向けのエンゲージメント向上研修や面談スキルの指導を提案する
- [ ] 従業員満足度（ES）調査やパルスサーベイの導入支援を行い、現状の課題を数値化する
- [ ] 離職防止に悩む企業へ向けた、社内コミュニケーション活性化のための人事制度改定をサポートする

**立場によって意見が分かれそうなポイント**

| 🧑 労働者目線 | 「日頃から自分の仕事や意見に耳を傾けてくれる上司が増えるなら、安心して働き続けられると思う。」 |
| 🏢 現場管理者目線 | 「日々の業務に追われる中で、100日間継続して新しいマネジメント手法を実践するのはスケジュール的に負担が大きい。」 |

## ② 専業主婦世帯などの国民年金「第3号」制度、厚労省が縮小に向け検討開始（全国・全世代）

**何が起きた？**
厚生労働省が、会社員や公務員に扶養される配偶者（主に専業主婦など）が加入する国民年金「第3号被保険者」制度について、縮小に向けた本格的な検討に入ったよ [Github Issue由来]。第3号被保険者は、自身で保険料を納めなくても基礎年金が受給できる仕組みとして長年続いてきたけれど、共働き世帯の増加やライフスタイルの変化に伴う不公平感の是正が長年の課題となっていたんだ。制度の見直しが進めば、今後の社会保険料の負担構造や働き方の選択に多大な影響を及ぼすという話だよ。

> 📖 **用語解説：国民年金「第3号被保険者」って？**
> 会社員や公務員（厚生年金加入者）に扶養されている20歳以上60歳未満の配偶者（年収130万円未満であることが多いよ）のことなんだ。自分で毎月の保険料を払わなくても、国民年金を受給できる特別な仕組みになっているんだよ。

**うちの仕事にどう関係する？**
- [ ] 顧問先の従業員やその配偶者に向けて、将来的な社会保険上の扶養基準（年収の壁）や年金制度変更の影響を周知する
- [ ] パート・アルバイト社員が「年収の壁」を意識して就業調整を行う際の相談に乗る
- [ ] 企業の人事担当者向けに、今後の社会保険適用拡大や第3号見直しを見据えた賃金・労働時間設計のアドバイスを行う

**立場によって意見が分かれそうなポイント**

| 立場 | 出てきそうな意見 |
|---|---|
| 👔 経営者目線 | 「第3号が縮小されれば、パート従業員の働き控えが減り、労働時間の延長や人手不足の緩和につながる可能性がある。」 |
| 🧑 労働者目線 | 「これまで免除されていた保険料を自分で払うことになれば、家計の負担が大きくなってしまう。」 |
| 🏢 現場管理者目線 | 「配偶者の扶養内調整を気にせずシフトに入れるようになれば、人員配置の計画が立てやすくなって助かる。」 |
| ⚖️ 専門家目線 | 「長年の社会構造に合わせて見直す時期に来ているが、急激な変更は低所得層の生活を圧迫するため慎重な経過措置が不可欠だ。」 |

## ③ 正社員の人手不足割合が53.6％に、上半期の人手不足倒産は過去最多を更新（全国・全業種）

> 📖 **用語解説：人手不足倒産って？**
> 従業員の退職や採用難、または賃上げに伴う人件費の高騰などが原因で、企業が事業を続けられなくなって倒産してしまうことなんだ。仕事の依頼（需要）があっても、人を集められなくて会社が潰れてしまうケースが増えているよ。

**何が起きた？**
帝国データバンクが2026年11月17日に公表した調査によると、2026年10月時点における正社員の人手不足を感じている企業の割合は**53.6％**となり、10月としては5年連続で5割を超えたよ。また、2026年度上半期（4月〜9月）における「人手不足倒産」は**225件**に達し、4年連続で過去最多を更新しているんだ。建設業や製造業、運輸業などで特に深刻で、賃上げムードが広がる一方で、人件費の高騰や採用難に耐えられない中小・零細企業の苦境が鮮明になっているという話だよ。

**うちの仕事にどう関係する？**
- [ ] 顧問先企業に対し、採用力強化のための賃金体系見直しや魅力ある人事評価制度の構築を提案する
- [ ] 補助金や助成金（キャリアアップ助成金など）を活用した、賃上げ原資の確保と定着率向上のサポートを行う
- [ ] 業務効率化や省人化を進めるための就業規則変更や、多様な働き方を認める人事労務コンサルティングを実施する

**立場によって意見が分かれそうなポイント**

| 立場 | 出てきそうな意見 |
|---|---|
| 👔 経営者目線 | 「賃金を上げないと人が採れないが、上げすぎると資金繰りが回らなくなるというジレンマに直面している。」 |
| 🧑 労働者目線 | 「人手不足で一人あたりの負担が大きくなっている割に、賃金が十分に上がらない職場からは転職を考えざるを得ない。」 |
| 🏢 現場管理者目線 | 「求人を出しても応募が全く来ず、現場の疲弊と離職の連鎖が止まらないのでどうにかしてほしい。」 |
| ⚖️ 専門家目線 | 「単なる採用活動の支援にとどまらず、価格転嫁を含めた収益改善とセットで労務管理を見直すアドバイスが求められる。」 |

## ⑤ニュース：国民健康保険料の上限額を2027年度に引き上げる案が提示される〈厚生労働省〉（全国・個人事業主・フリーランス）

**何が起きた？**
厚生労働省は、自営業者やフリーランスなどが加入する国民健康保険（国保）の保険料を巡り、医療費などの給付に充てる「医療分」の年間上限額を、2027年度から3万円引き上げて「96万円」とする方針を社会保障審議会の医療保険部会に示し、大筋で了承された。上限額の引き上げは2022年度以来、6年連続となる。

**背景と論点**
今回の引き上げは、少子高齢化に伴う医療費の増大に対応するため、高所得層により多くの負担を求めて中間所得層の急激な保険料上昇を抑える「応能負担」の観点から実施されるもの。医療分の上限に達するのは年収約1170万円以上の世帯と推計されており、影響を受けるのは加入世帯全体の約1.73％にとどまる見込み。なお、40〜64歳が対象の「介護保険分」の上限は17万円で据え置かれる。

**うちの仕事にどう関係する？**
- [ ] 個人事業主やフリーランスの顧問先に対し、2027年度からの国保料上限引き上げ（医療分96万円）の可能性をあらかじめ周知する
- [ ] 高所得帯の個人事業主において、法人成り（マイクロ法人など）による社会保険料の最適化シミュレーションのニーズが高まる可能性があるため、提案の準備をしておく
- [ ] 国保料は自治体ごとに算定方式や保険料率が異なるため、自社（自身）の自治体の動向や今後の料率改定にも注意を払う

**立場によって意見が分かれそうなポイント**

| 立場 | 意見・懸念点 |
| :--- | :--- |
| **経営者（個人事業主）** | 「また上限が引き上げられるのか。会社員との社会保険料の格差や、現役世代ばかりが負担を背負わされる構造に納得がいかない」 |
| **労働者（会社員）** | 「直接対象にはならないが、高齢化に伴う社会全体の医療・社会保障費の膨らみは他人事ではなく、将来の負担が心配だ」 |
| **現場管理者（自治体担当者）** | 「高所得層への配慮や財源確保の理屈は分かるが、毎年のように上限や料率の見直し・賦課作業が発生し、窓口対応や説明の負担が大きい」 |
| **専門家（社労士・税理士）** | 「応能負担の趣旨は理解できるが、際限のない上限引き上げは保険料の税金化を招きかねない。フリーランスの防衛策として法人化の検討がさらに増えるだろう」 |

## ⑥📚コラム：【運送業の労務管理】改善基準告示違反の「上位3項目」を防ぐ——事後対応から事前予防への転換実務

> 📖 **用語解説：改善基準告示とは？**
> トラック、バス、タクシーなどの自動車運転者の労働時間を適正に管理し、過労運転を防止するため厚生労働大臣が定める基準。一般の労働時間規制とは異なる特例や上限が設けられており、違反すると行政処分の対象となる。

**どういう話？**
2024年4月の時間外労働規制の適用開始以降、運送業界では「改善基準告示」の遵守が死活問題となっている。しかし、実務現場では依然として違反が後を絶たない。特に違反になりやすい「上位3項目（拘束時間の管理、休息期間の確保、連続運転時間の制限）」について、紙の点数計算や属人的な配車管理のままでいることが、知らぬ間に法令違反を生む最大のリスクとなっている。事後的な帳票の辻褄合わせではなく、配車段階からの事前予防システムへの転換が急務である。

- [ ] デジタルタコグラフや労務管理システムの導入・活用状況を確認し、手動による管理ミスや入力漏れを防ぐ体制を構築する

## ⑦🥊今日のスカッと労働判例：内部通報の報復人事にご用心！あおぞら銀行事件・最高裁決定が示す「会社側の違法な報復」に対する司法の鉄槌

> 📖 **用語解説：公益通報者保護法**
> 組織内の不正行為を外部や行政機関、内部の窓口に通報した労働者が、解雇や降格、減給などの不利益取扱（報復人事）を受けることから守るための法律。通報者の正当な権利を守る盾として機能する。

**どんな話？**
会社の不正を内部通報した従業員に対し、組織が露骨な報復として左遷や不当な人事異動、降格を行った――そんなドラマのような話が現実にある。あおぞら銀行をめぐる一連の紛争（最高裁決定）では、内部通報を行った労働者に対する会社の不利益処分が「公益通報者保護法に反する、または権利の濫用である」として、会社側の違法性が厳しく指弾された。正当な告発を握りつぶそうと権力を振りかざした会社に対し、最高裁が下した決定は、コンプライアンスを軽視する経営陣にとってまさに「司法の鉄槌」となった。

**うちの仕事にどう関係する？**
- [ ] 内部通報制度の窓口が形骸化していないか、また通報者を守る秘密保持や不利益取扱禁止の規定が実効性を持っているか点検する
- [ ] 業績や評価とは無関係に、経営陣や上層部を批判した者やトラブルを告発した者を不自然に遠ざける人事を行っていないか、リスク管理を徹底する
- [ ] 顧問先でトラブルの予兆や内部告発があった際、感情的な報復人事ではなく、適正な事実調査とコンプライアンスに則った対応をアドバイスする

| :--- | :--- |
| **経営者** | 「組織の秩序やマネジメント上の裁量権の範囲内で行った人事なのに、何でもかんでも『報復』と結びつけられると、人事権が縛られて経営がやりづらい」 |
| **労働者** | 「会社のために勇気を出して不正を告発したのに、逆に閑職に追いやられたり冷遇されたりしたら、誰も怖くて声を上げられなくなる。司法が守ってくれて本当によかった」 |
