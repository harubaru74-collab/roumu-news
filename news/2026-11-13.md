## ③ 同一労働同一賃金ガイドラインの2026年10月改正、実務対応の徹底が急務に（全国・全業種）

> 📖 **用語解説：同一労働同一賃金って？**
> 同じ会社で働いているのだから、正社員でもパートやアルバイト、契約社員といった非正規雇用であっても、仕事の内容が同じなら給料や手当も同じにしようね、というルールのことなんだ。不合理な差をつけてはいけないと法律で決まっているよ。

**何が起きた？**
2026年**10月1日**に施行・適用された改正パートタイム・有期雇用労働法および「同一労働同一賃金ガイドライン」を受け、企業における実務対応が本格化しているよ。今回の改正では、賞与や退職手当、各種手当、病気休職などの待遇差に関する判断基準が具体化されたほか、雇い入れ時に「正社員との待遇差について説明を求めることができる旨」を明示することが新たな法的義務となったんだ。

**うちの仕事にどう関係する？**
- [ ] 顧問先の労働条件通知書や雇用契約書のひな形を点検し、新設された説明要求に関する記載漏れがないか確認・修正する
- [ ] 企業の賃金規程や各種手当（通勤手当・家族手当など）の支給基準を見直し、非正規雇用者との間に「不合理な差」がないかスポット監査を実施する

**立場によって意見が分かれそうなポイント**

| 立場 | 出てきそうな意見 |
|---|---|
| 👔 経営者目線 | 「人件費全体の総額管理が難しくなるなか、すべての手当や賞与の差に客観的な根拠を説明するコストが重すぎる」 |
| 🧑 労働者目線 | 「同じように責任ある業務をこなしている以上、正社員との不合理な格差は速やかに是正されるべきだ」 |
| 🏢 現場管理者目線 | 「スタッフから待遇差の理由について質問された際、人事の評価基準を現場の管理者がどこまで説明できるか不安がある」 |
| ⚖️ 専門家目線 | 「単なる形式的な規程の修正だけでなく、職務の内容や人材活用の仕組み（人事考課）の全体像をセットで見直す必要がある」 |

## ⑤ニュース：新卒の正社員採用で「通年採用」が52％に拡大、前年から2ポイント増〈厚生労働省〉（全国・全業種）

> 📖 **用語解説：通年採用とは？**
> 従来の「一括採用（新卒者が一斉に4月に入社する仕組み）」にとどまらず、時期を限定せずに年間を通じて随時、新卒学生の募集や採用を行う手法のこと。

**どういう話？**
厚生労働省が公表した労働経済動向調査によると、2025年度の新卒採用で正社員を募集した事業所のうち、52％が「年間を通じて随時行った」と回答した。前年度と比較して2ポイント増加しており、新卒採用における通年化が着実に広がっていることが明らかになった。背景には、深刻な人手不足の中で優秀な学生を確保するため、採用活動の時期を柔軟化せざるを得ない企業の事情がある。また、春季のみの募集を行った事業所は25％と微減しており、今後は年間を通じた柔軟な採用戦略が企業の標準になりつつある。

**うちの仕事にどう関係する？**
- [ ] 顧問先企業に対し、従来の「4月一括採用」にこだわらない柔軟な採用スケジュール（通年採用）の提案を行う
- [ ] 通年採用の導入に伴い、入社時期に応じた研修体系や給与・評価制度の整備（同期入社制度の変更など）をサポートする
- [ ] 採用活動の長期化・常態化を見据えた人事・採用担当者の労務負担軽減策をアドバイスする

| 立場 | 意見・懸念点 |
| :--- | :--- |
| **経営者** | 採用の窓口を広げることで、優秀な人材を取り逃がすリスクを減らせるため前向きに捉えたい。 |
| **労働者** | 留年や留学、自分のペースでの就職活動など、多様なタイミングで正社員を目指しやすくなる。 |
| **現場管理者** | 年間を通じて新人が入社するため、OJTや教育の負担が分散する一方で、受け入れ体制の常時化が求められる。 |
| **専門家（社労士等）** | 通年採用化に伴う労務管理の複雑化（労働条件通知や社会保険手続の随時発生など）に注意を促す必要がある。 |

> 📖 **用語解説：人手不足倒産とは？**
> 従業員の退職、求人難、人件費高騰などを直接の原因、あるいは背景として、事業継続が困難になり倒産に追い込まれる企業のことを指す。

**どういう話？**
帝国データバンクの集計によると、2026年度上半期（4月〜9月）における「人手不足倒産」の件数が225件に達し、前年同期を上回って4年連続で過去最多を更新した。物価高や最低賃金の引き上げに伴う人件費の高騰に加え、深刻な働き手不足が中小企業の経営を直撃している実態が浮き彫りになった。特に「建設業」「運輸業」「サービス業」などで件数が目立ち、十分な賃上げ原資を確保できないまま人材が流出し、事業継続を断念するケースが後を絶たない。単なる採用難にとどまらず、収益構造の改善や価格転嫁が急務となっている。

**うちの仕事にどう関係する？**

- [ ] 度重なる最低賃金引き上げや賃上げ要請に対し、適正な価格転嫁とセットになった賃金体系の見直しを支援する
- [ ] 離職防止のためのエンゲージメント向上策や、働きやすい職場環境づくりのコンサルティングを強化する

| :--- | :--- |

| **労働者** | 会社の経営難や人手不足による過重労働、さらなるインフレへの不安が拭えない。 |
| **現場管理者** | 人が辞めても補充がきかず、残されたスタッフへの負担が限界に達している。 |
| **専門家（社労士等）** | 採用支援や賃金設計だけでなく、業務効率化やDX推進を踏まえた総合的な労務提案が求められる。 |

> 📖 **用語解説：アウティングとは？**
> 本人の了解を得ずに、その人の性同一性（SOGI）やセクシュアリティ、あるいは障害や病気といった機微な個人情報を、第三者に暴露する行為のこと。

**どんな話？**

- [ ] 発達障害やメンタル不調を抱える従業員への対応では、一方的な処分ではなく「合理的配慮」のプロセスを必ず記録・実行する
