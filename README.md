# roumu-news

社労士・行政書士業務向けの労務ニュース日次まとめリポジトリ。

毎朝、その日の労務関連ニュースを検索し、以下の3段構成でまとめて `news/` 配下に保存します。

1. **ニュースの要約** — その日の主要な労務ニュースの箇条書き
2. **現職（社労士・行政書士業務）への影響と対応** — 顧問先対応・実務への影響と推奨アクション
3. **賛否両論の視点** — 論点のある改正・施策について、賛成/慎重（反対）双方の視点を整理

## ディレクトリ構成

```
news/
  YYYY-MM-DD.md   各日のまとめ
```

## 自動実行について

毎日朝6時に自動実行するルーティンとして運用しています。詳細は [`ROUTINE.md`](./ROUTINE.md) を参照してください。
